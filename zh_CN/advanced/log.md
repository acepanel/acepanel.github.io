# 日志

![日志](/images/log/log.png)

顶层 **日志**模块集中展示面板审计数据和实时系统日志，包含 **操作日志**、**数据库日志**、**HTTP 日志**和 **SSH 日志**。

## 日志类型

| 标签页     | 内容                                     |
| ------- | -------------------------------------- |
| 操作日志    | 通过 AcePanel 执行的管理操作， 可用于确认谁在什么时间修改了资源。 |
| 数据库日志   | 面板记录的数据库相关操作， 不能替代数据库引擎完整的慢查询、错误或审计日志。 |
| HTTP 日志 | 面板审计记录器可用的 HTTP 请求活动和响应信息。             |
| SSH 日志  | 增量加载 SSH 服务的登录、认证失败等事件。                |

应用、网站、容器、项目、任务和 systemd 日志从对应资源页面打开，但使用相同的实时查看器。

## 实时日志查看器

查看器会显示连接状态并增量加载新日志， 支持：

- 加载更早的历史记录；
- 在当前已加载内容中搜索；
- 跳转到上一个或下一个匹配项；
- 切换自动换行；
- 复制全部已加载文本；
- 在日志源支持时下载；
- 在所选日志支持时清空；
- 进入或退出全屏。

搜索不会查询磁盘上的整个日志文件。 应先加载需要的历史记录，再执行搜索。 历史日志很大时，下载后使用命令行工具处理，不要在浏览器中反复加载。

## 清空与保留

清空日志是破坏性操作，可能删除故障排查或安全事件调查所需证据。 正在进行审计或事故分析时，应先下载日志。 部分 systemd 和 SSH 日志属于系统日志的增量视图，其保留时间由底层服务或 journal 配置决定。

使用[日志清理](./toolbox/log)扫描可释放空间的面板、网站、数据库、容器和系统日志。 日志清理不会删除普通网站文件、数据库表或容器卷。

## 故障排查

- **连接断开：** 保持对话框打开等待重连；仍没有新数据时，检查对应资源和面板服务。
- **搜索不到旧记录：** 加载更多历史或下载日志。
- **内容乱码：** 确认产生日志的进程使用 UTF-8 编码。
- **没有操作记录：** 确认该操作确实通过面板完成，而不是直接在服务器上执行。
