# 网站

![Website overview](/images/website/overview.png)

网站模块用于管理 Web 服务器上的站点配置。 AcePanel 支持三种类型的网站：反向代理、PHP 和纯静态。

## 前置要求

使用网站功能前，需要先安装 Web 服务器：

1. 进入 **应用** > **原生应用**
2. 安装 Nginx、OpenResty、Apache、OpenLiteSpeed 或 Caddy

## Web 服务器功能

所有受支持的 Web 服务器均可使用各类网站，但部分设置取决于当前服务器：

| 面板功能         | Nginx / OpenResty | Apache | OpenLiteSpeed | Caddy |
| ------------ | ----------------- | ------ | ------------- | ----- |
| 访问统计         | 支持                | 未提供    | 未提供           | 支持    |
| 默认站点选择       | 支持                | 未提供    | 未提供           | 支持    |
| 显式 IPv6 监听设置 | 支持                | 未提供    | 支持            | 未提供   |
| LSCache 设置   | 未提供               | 未提供    | 支持            | 未提供   |

此表描述的是 AcePanel 提供的设置项，并非底层服务器支持的全部功能。编辑器会显示适用于当前服务器的设置。 PHP 网站在 OpenLiteSpeed 下使用 LSAPI；参见 [PHP 运行环境管理](./app/environment#openlitespeed-下的-php)。

在 OpenLiteSpeed 下，**高级设置 > LSCache** 控制单个网站的缓存。请在 OpenLiteSpeed 应用管理页面配置其真实 IP 处理方式。网站目录和运行目录字段提供目录选择器，并支持新建目录。

## 切换 Web 服务器

切换当前 Web 服务器前，请备份网站配置。选定新服务器后，可通过 CLI 为其重建所有网站配置：

```bash
acepanel website rebuild
```

重建时会读取原服务器的配置，并在支持的情况下迁移域名、目录、HTTPS、PHP 版本、上游、代理、重定向和基本身份验证等通用设置。**重写规则、自定义配置、限流和真实 IP 设置不会迁移。** 重建成功后会移除原配置目录，因此请自行保留备份，并使用新服务器的语法重新配置这些设置。不受支持的显式 IPv6 监听地址也会被移除。

请检查命令输出，并在之后逐一验证各个网站。打开网站编辑器不会自动为其他服务器重建配置。

## 网站类型

| 类型                      | 说明         | 适用场景                                |
| ----------------------- | ---------- | ----------------------------------- |
| [反向代理](./website/proxy) | 将请求转发到后端服务 | Node.js、Go、Java 等应用 |
| [PHP](./website/php)    | 运行 PHP 程序  | WordPress、Laravel 等                 |
| [纯静态](./website/static) | 托管静态文件     | HTML、Vue/React 构建产物                 |

## 网站列表

除 **全部**、**反向代理**、**PHP** 和**纯静态**外，页面还提供 **统计**和[**设置**](./website/setting)标签页。

网站列表显示以下信息：

- **网站名称**：站点的唯一标识
- **网站类型**：反向代理、PHP 或纯静态
- **运行中**：站点是否启用
- **目录**：网站文件所在目录
- **HTTPS**：是否启用 HTTPS
- **证书到期**：SSL 证书到期时间
- **到期**：网站到期时间，到期后会自动停止网站
- **备注**：自定义备注
- **操作**：编辑、删除等

### 搜索与排序

使用列表中的关键词搜索查找网站。对于带排序控件的列，点击表头即可排序；其他资源列表也采用同样的方式。

域名在不同网站之间必须唯一。将域名绑定到其他网站前，请先从原网站中移除。

## 创建网站

1. 进入 **网站** 页面
2. 选择网站类型标签（反向代理/PHP/纯静态）
3. 点击 **创建网站**
4. 填写网站信息
5. 点击创建

### 通用配置项

- **名称**：网站的唯一标识，仅允许字母、数字、连字符和下划线；创建后不可更改
- **域名**：绑定的域名，可添加多个（粘贴以逗号/空格/换行分隔的内容可批量添加）
- **端口**：监听的端口，默认 80
- **备注**：可选的备注

类型专属项：

- **反向代理**：需要填写 **代理目标**（例如 `http://127.0.0.1:3000`）
- **PHP**：需要选择 **PHP 版本**，并可在创建网站的同时选择创建 **数据库**（数据库名/用户/密码）
- **PHP / 纯静态**：支持自定义网站 **目录**（留空时默认为 `网站目录/网站名/public`）

## 网站管理

点击网站的 **编辑** 按钮进入管理页面，该页面按标签页组织：

- **域名与监听**：修改绑定的域名和监听端口
- **基本设置**：网站目录、运行目录、默认首页文件
- **上游** / **代理**：配置后端上游和代理行为（仅反向代理网站）
- **HTTPS**：绑定 SSL 证书、HTTP 重定向、HSTS、OCSP、TLS 版本
- **伪静态**：设置重写规则（仅 PHP 网站）
- **重定向**：配置重定向规则
- **高级设置**：访问统计、日志设置、限速、真实 IP 和基础认证
- **自定义配置**：添加自定义配置片段（站点级或共享）
- **访问日志** / **错误日志**：实时查看网站的日志

### 切换网站类型

现有反向代理、PHP 或纯静态网站可以切换为另外两种类型。 AcePanel 会保留名称、域名、监听地址、目录、文件、HTTPS 关联、到期时间等通用字段，删除原类型专属 Web 服务器配置，并为新类型生成配置。

切换前先备份网站。切换后必须重新检查或配置上游和代理规则、PHP 运行环境与 Rewrite，以及静态网站专属行为。AcePanel 会在应用前测试生成的 AcePanel 会在应用之前测试生成的 Web 服务器配置，并在验证失败时显示当前 Web 服务器的具体错误。

## 批量创建

点击 **批量创建网站** 可一次性创建多个网站，适用于需要快速部署多个站点的场景。

## 删除网站

删除网站时，需要进行 5 秒的确认倒计时。你可以选择是否同时 **删除网站目录** 以及 **删除同名的本地数据库**。  AcePanel 还会解除网站与证书的关联，并删除对应的防篡改规则。
