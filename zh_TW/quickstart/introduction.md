# 產品介紹

![AcePanel home dashboard](/images/home/home.png)

AcePanel 是一款開源的伺服器運維管理面板。

## 特性

- **極低佔用**：採用 Go 語言開發，單一檔案執行，資源佔用極低
- **低破壞性**：盡可能減少對系統的變更，為同類產品中最少
- **追隨時代**：對新系統相容性好，技術棧保持更新
- **高效維運**：功能完善、客製化能力強，適用於簡單到複雜的各種部署情境
- **離線執行**：支援離線模式，停止面板不影響已部署的服務
- **安全穩定**：具備多重安全機制，可在正式環境長期穩定執行
- **完整開源**：全部程式碼開源，可自由修改和二次開發
- **永久免費**：面板本體不會引入任何收費功能

## 功能

**快速建站**

深度整合 Nginx、MySQL、PHP 等主流服務，一鍵部署 LNMP 環境，支援多版本共存。

**檔案管理**

提供類似 Windows 檔案總管的操作體驗，支援快速鍵、批次操作與線上編輯。

**備份恢復**

為網站、MySQL、PostgreSQL、ClickHouse、Redis 和 Valkey 提供備份與恢復，並支援計劃任務以及本地、S3、SFTP、WebDAV 儲存。

**監控與安全**

提供系統歷史監控、可配置告警、SMTP 和事件通知、防火牆規則、掃描感知以及 Linux 防篡改。

**容器與專案**

管理 Docker 或 Podman 容器、Compose、映象、網路、卷，以及由 systemd 管理的 Go、Java、Node.js、PHP、Python、.NET 和通用專案。
